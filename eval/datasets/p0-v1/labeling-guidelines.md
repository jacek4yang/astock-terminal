# P0 评测集标注规范

## 时间切分与未见测试集

训练集截至 2024-12-31，开发集截至 2025-12-31，测试集从 2026-01-01 开始。规则、提示词和实体词典只能依据训练/开发切分调整；测试切分用于合并与发布门禁，不得针对单个测试样例添加规则。

每个样例必须有不可变 ID、事件时间、行业、市场状态、困难标签、许可声明和离线快照引用。快照升级必须创建新数据集版本，不能原地替换。

## 新闻与事件

同一事实的转载属于同一 `canonical_group`。单纯换标题、调整语序或增加无实质信息的点评不算新事件。正式更正或撤回既与原事件关联，也必须单独标记。旧闻率以事件实际发生/首次公开时间为准，不以转载时间为准。来源页面失效时保留许可允许的哈希、必要字段和定位信息。

虚假快讯必须由官方公告、交易所页面或至少两个相互独立的一手来源证伪，不能仅以模型判断标注。

## 实体链接

优先链接到稳定的规范实体 ID。证券、公司法人、子公司、品牌、产品和行业分别标注；上下文只谈品类而非企业时，`gold_id` 应为 `null`。同名实体至少使用地区、统一社会信用代码、证券代码、上下游关系或公告主体中的两项证据消歧。

## 图谱与传导

边方向按语义定义而非句子语序。关系必须包含类型、方向、有效期和可复核证据定位。隐含关系只有在跨段信息能组成明确逻辑链时才标注，常识推测不算金标准。

传导路径按节点序列精确比较；方向表示对路径终点的影响。滞后用交易日/自然日约定后的天数，区间校准使用冻结快照之后的已实现影响回放。

## Agent

逐条拆分可核验事实，检查引用是否真的支持该句；数字按单位、口径、日期和复权方式比较。来源冲突必须明确展示冲突、解释采用口径并降低置信度。没有足够数据时，拒绝给出确定性结论才算正确。

延迟、token 和 API 成本使用冻结的执行轨迹元数据，不在离线重跑时调用在线模型。

## 争议与许可

两名标注者独立完成，分歧由第三名标注者裁决。仍无法确定的样例移出门禁集并记录到争议清单。只允许合成 CC0、明确可再分发资料或公开事实的必要短摘要；受限正文不入库。
