# 量化与交易计划方法

## 确定性优先

技术、缠论、市场状态、关系、回测指标和计划价位均由 Rust 计算。LLM 负责研究路径和解释，不负责生成数值。

## 回测

回测使用交易规则层约束 T+1、手数、板块涨跌停、费用、印花税和不可成交拒单。结果包含净值、回撤、CAGR、波动、Sharpe、Sortino、胜率、盈亏比、费用和成交尾部。

策略迭代工具将候选数量限制为 16，使用三个时间窗口比较收益、风险和稳定性，并报告参数敏感性。它是稳健性筛查，不等于严格样本外验证；不以单一最优参数作为未来有效证据。

## ManualTradingPlan

入场区由最新收盘与 ATR14 附近的审慎区间得到；止损组合 20 日结构支撑和波动距离；目标优先使用确定性看涨形态或结构阻力，缺失时使用风险单位作为复核目标。计划包含：

- 正反论点、市场环境和置信度；
- 账户最大风险预算，而非含糊仓位百分比；
- 基准、高开、转弱等条件情景；
- 集合竞价、开盘、上午、午间、尾盘检查点；
- T+1、板块涨跌停、最小手数约束；
- 价位依据、数据来源、截至时间和失效条件。

这些价位是规则化风险管理锚点，不是价格预测或收益承诺，且软件不会据此下单。

## 偏差与限制

免费数据源不能完全消除幸存者偏差、点时财务覆盖不足和事件漏报。凡缺少严格 PIT 数据、独立样本或成本敏感性验证的结论必须降低置信度。历史表现不代表未来表现。
