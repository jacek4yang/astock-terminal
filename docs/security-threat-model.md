# Agent 外部内容与工具安全威胁模型

本文对应 GitHub Issue #17，定义新闻、公告、网页、PDF、MiniMax 联网搜索和 Agent 工具调用进入 AStock Terminal 时不可绕过的安全边界。该边界的目标不是判断资讯是否真实，而是确保攻击者控制的内容不能改变系统规则、扩大工具权限、读取本地隐私或把秘密发送到外部。

## 保护对象

- MiniMax、问财、聚宽等上游凭据及系统密钥环中的秘密。
- 本地 SQLite、Parquet、自选股、对话、策略和研究报告。
- Agent 的系统提示、用户锁定的工具清单和工具权限域。
- 用户机器、内网服务、云主机元数据地址与本地文件。
- 分析结论的证据来源、任务状态和审计可追溯性。

## 信任边界

用户在界面中直接提交的意图属于“用户请求”，但仍不等于自动授权外部写操作。模型生成的计划属于“模型计划”。新闻标题、搜索摘要、HTML、PDF 文本、公告正文、来源页和其重定向目标一律属于“不可信外部数据”。

外部数据必须作为结构化数据载荷进入模型，带有 `trust=untrusted_external_data` 与 `can_authorize_tools=false`。它不得拼接到系统或开发者提示中，也不得修改工具清单、权限域、模型配置、安全规则或后续请求的角色。

## 攻击者能力

假定攻击者可以控制网页或 PDF 的全部文本、MIME 声明、响应大小、压缩编码、重定向链和 DNS 回答，也可以在看似正常的财经内容中混入中英文提示注入。攻击者还可能诱导模型读取本地文件、数据库或密钥，调用未来新增的写工具，访问 `localhost`、私网、链路本地地址和云元数据服务，或通过错误信息及日志泄漏秘密。

## 强制控制

### URL、DNS 与重定向

- 只允许 HTTP/HTTPS，不允许 URL 凭据、`file:`、`ftp:`、`gopher:` 等协议。
- 只开放 80/443 端口；明确阻断 localhost、`.local`、`.internal`、`.lan`、元数据主机、环回、私网、链路本地、保留、测试网段、组播和未指定地址。
- 发请求前解析 DNS；只要任一回答属于禁止地址就拒绝。连接固定到已验证的地址，避免“检查时公网、连接时内网”的 DNS 重绑定。
- HTTP 客户端关闭自动重定向。每一跳重新解析 URL、重新做 DNS 检查并计入最大 5 跳上限；公网地址重定向到内网时立即拒绝。
- MiniMax 搜索返回的链接与其他来源使用相同策略，不因供应商可信而放宽。

### 下载与解析资源上限

- 单次请求默认 20 秒、连接 5 秒；这些是网络安全边界，不是 Agent 后台任务的总时限。
- 单个响应最大 8 MiB，同时检查 `Content-Length` 和实际流式读取字节数。
- 安全抓取只请求并接受 `identity` 编码，拒绝压缩响应，避免解压炸弹。
- MIME 白名单限于 HTML、纯文本、JSON、XML 和 PDF；拒绝可执行文件、压缩包及任意二进制。
- 文本送入模型前再次做字符数截断；PDF/HTML 解析器后续接入时仍必须在此抓取边界之后运行，并设置页数、节点数、递归深度和解析时间上限。

### 提示注入与工具隔离

- 外部文本进行密钥脱敏和提示注入信号检测，命中时保留证据但显式标记，不把内容当指令执行。
- 每个工具在注册处拥有不可由模型修改的权限域：只读网络、只读本地、纯计算或外部写入。
- 每轮用户选择的工具清单是不可扩张的白名单；模型只能在清单内调用。
- 外部内容不能读取本地数据；模型计划和外部内容都不能直接授权外部写入。未来新增交易、发帖、上传或修改外部系统的工具，必须走明确的用户确认入口。
- 当前工具集不提供任意 Shell、任意文件、任意 SQLite 或密钥环读取能力。

### 脱敏与审计

- 统一递归脱敏 API key、token、secret、password、Authorization、Cookie、credential 以及 Bearer 值。
- 工具审计表为追加式，只记录任务 ID、调用 ID、工具名、权限域、调用来源、SHA-256 参数指纹、生命周期事件、耗时和时间戳。
- 审计永不保存原始参数、网页/PDF 正文、工具结果、供应商错误文本或凭据。参数指纹仅用于关联重试。
- 安全拒绝仍产生审计事件；审计写入失败不阻塞分析，但会发出不含本机路径和敏感正文的结构化告警。

## 验证矩阵

- 单元与属性测试覆盖 RFC1918 地址族、IPv4/IPv6 环回、元数据地址、不安全协议和端口。
- DNS 重绑定测试要求“公网 + 私网”混合回答整体拒绝。
- 重定向测试验证每跳重新检查，公网到元数据地址被拒绝。
- HTML 与 PDF 提示注入样本验证不能授权工具，且密钥在模型载荷中已脱敏。
- 流式超大响应测试验证在边界字节处停止，不把越界块写入内存。
- 工具权限测试覆盖关闭工具、外部内容读本地和模型计划发起外部写入三类拒绝。
- 存储测试验证审计顺序与元数据字段。CI 对整个工作区运行测试、Clippy，并通过 RustSec 检查 Rust 依赖漏洞。

## 剩余风险与上线检查

搜索结果或公告仍可能包含虚假事实，提示注入检测也不等同于内容真伪验证；结论层必须继续使用多来源交叉验证、引用校验和置信度表达。浏览器型自动化如后续允许执行脚本，需要独立进程、网络和文件沙箱，不能复用普通研究工具权限。

新增外部数据源或工具时，评审者必须确认其经过统一 URL/抓取边界、外部文本封装、脱敏、权限域和审计链。任何绕开这些入口的直接 HTTP 请求都应被视为安全回归并阻止发布。
