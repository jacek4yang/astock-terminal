## 二、精选 14 个最适合 A 股散户日频移植的策略

> 入选标准:日频可跑、逻辑清晰、参数少、与我们回测引擎能力匹配(单标的 on_bar 或截面选股日频调仓)、不依赖期货/分钟/Level2/ML。

### S1. ETF 动量轮动 + RSRS 择时(社区迭代最多的体系)
- 来源:2023/4,15,37,47;2024-2/24,50,60 等十几个版本。
- 核心逻辑(伪代码):
  ```
  每日: 对 ETF 池(5~10 只宽基/行业)计算 score = 25日 log 价回归斜率年化 × R²
       rsrs = zscore(18日 high~low OLS 斜率, 窗口M=600) × 当日R²
  if rsrs > 0.7:  持有 score 最高的 1 只 ETF(满仓)
  elif rsrs < -0.7: 清仓(可换货币ETF)
  else: 维持
  ```
- 指标:线性回归斜率/R²、RSRS(N=18, M=600, 阈值 ±0.7)。
- 声称绩效:8 年 10–50 倍、年化 60%(各版本不一,**未验证**,且多数用 2021–2024 创业板/纳指行情,有过拟合嫌疑)。
- 适配注意:ETF 无涨跌停问题(仍有 ±10%)、T+1 可直接对应;RSRS 需 600+ 日历史斜率序列做标准化,冷启动长。

### S2. 波动率过滤 + 最小相关 ETF 轮动(2025/26)
- 核心逻辑:
  ```
  每日: 729 日日收益 → 剔除年化波动率∉[5%,33%] → 取平均相关系数最小的 4 只
       对 4 只计算 score = 25日回归年化收益 × R²,买第 1 名,单标的满仓轮动
  ```
- 声称绩效:原文未给夸张数字,结构上是「风险平价思想 + 动量」组合,逻辑干净。
- 适配注意:纯日频、单标的,是我们引擎的「教科书级」样例;729 日相关矩阵可用增量计算。

### S3. 行业 ETF 轮动 + BBI 大盘择时(2024-2/21)
- 核心逻辑:7 个大盘指数 30 分钟 BBI 判断可否开仓(可改日频);17 只行业 ETF 按日频 BBI(21/34/55/89 斐波那契)乖离最大者全仓;大盘转空换银华日利。
- 声称绩效:2015 至今年化 35%、回撤 16%(**未验证**)。
- 适配注意:BBI=(MA21+MA34+MA55+MA89)/4,实现极简单;周频调仓(周三)对散户友好。

### S4. 国九小市值策略(2025/6,zycash 框架)
- 核心逻辑:
  ```
  每周二: 中小板指成分 → 过滤 ST/次新/停牌/涨跌停/股价>50
         → 净利润>0 & 营收>1亿(国九条排雷) → 市值最小 N 只
  动态 N: 指数 close − MA10 分档 → 持仓 3~6 只
  空仓月份: 1月、4月持有货币ETF
  止损: 个股 −9% 止损 / 盈利 100% 止盈 / 市场平均跌幅>5% 清仓
  ```
- 声称绩效:年化 100.5%、回撤 25.6%(**未验证**;小市值因子 2024 年初曾崩盘,需警惕)。
- 适配注意:截面选股 + 日频调仓的完美样例;1/4 月空仓是A股季节性经验,可选配。

### S5. 菜场大妈:股息率 + PEG + 小市值(2024-1/36,2025/35)
- 核心逻辑:月频;近 1 年分红/市值 = 股息率前 25% → PEG<0(原代码口径)且 PB<3 → 按市值升序取 5 只等权。
- 声称绩效:10 年 206 倍(**未验证**,小市值+低价风格暴露极大)。
- 适配注意:分红数据我们可用「近 12 个月每股分红/股价」近似;行业中性版本见 2025/40。

### S6. 高股息策略·行业中性版(2025/40)
- 核心逻辑:连续 5 年均有分红 → 当年股息率排序 → 申万一级行业每行业最多 2 只 → 股息率>4% 才买入,周频调 10 只。
- 声称绩效:稳健型,原文未标夸张年化。
- 适配注意:行业中性是现成的风控模板;适合作为低波策略基线。

### S7. 大盘择时,逻辑简单(2025/23)

- 声称绩效:逻辑简单无夸张标题。
- 适配注意:MACD(12,26,9) 单指标开关仓,是「择时模块」最小可行实现。

### S8. 首板低开策略·终极版(2025/78,打板类代表)
- 核心逻辑:
  ```
  盘前池: 昨日首板(close==high_limit) ∧ 非ST ∧ 上市>60天 ∧ 前日无涨停 ∧ 15日相对位置低
  9:30: 今日低开 → 等权买入
  11:25: 有浮盈且未涨停 → 止盈;  14:30: 未涨停 → 无条件清仓(T+1 隔日交易)
  风控: 昨日跌停或亏损>4% → 开盘即卖
  ```
- 声称绩效:最大回撤 15%、年化 50%(**未验证**)。
- 适配注意:本质是「T+1 隔夜」策略,日频引擎用今开买、次日尾盘卖即可近似;涨停买不进要处理。

### S9. BOLL 超跌反转(2024-2/26)
- 核心逻辑:中小板流通市值最小 50 只池;`前日收盘 < BOLL下轨(20,2) 且 今日收盘 > 前日收盘 且 > 近10日低点` → 买入;止损价 = 近 10 日最低;触及上轨后滞涨卖出。
- 声称绩效:「近几年一直有效」(**未验证**)。
- 适配注意:日频、条件全部为收盘价比较,移植零障碍;单标的止损用前低而非固定百分比,值得借鉴。

### S10. 超跌反弹 MA55 反转(2024-2/30)
- 核心逻辑:近 40 日内仅 1–3 天站上 MA55、近 3 日重新上穿、且 10 日低点=60 日低点 → 买;ROE>0 排序取前 5;止损 −5%。
- 声称绩效:3 年 2.3 倍(**未验证**)。
- 适配注意:「长期受压于均线后首次收复」是经典的底部反转量化定义,参数(40/3/55)需重调。

### S11. 海龟突破系统(2023/44)
- 核心逻辑:沪深300 成分股,盘中价突破 55 日最高价且近 9 日下跌(回调后突破)→ 全仓 1 只;止损=成本×(1−近3日最大振幅),止盈=成本×(1+2×振幅)。
- 声称绩效:19–21 年化 150%(**未验证**,单票全仓风险极高)。
- 适配注意:唐奇安通道 55/20 经典参数;止损用「近期振幅」自适应波动率,比固定%合理;建议改成最多持有 3–5 只。

### S12. zscore 均值回归(2020/12)
- 核心逻辑:`sub = close − MA20;z = (sub − mean60(sub)) / std60(sub)`;z ≤ −2 买,z ≥ +1 卖,单标的。
- 声称绩效:「胜率100%」——**典型标题党/过拟合**(单票 601238、参数拟合)。
- 价值:代码 30 行,是验证我们引擎正确性的最佳 smoke-test 策略;zscore 计算模块可直接复用。

### S13. 配对交易(2022/66 + 2020/13)
- 核心逻辑:两只高相关股票,`spread = p1 − p2`(或 p2 − β·p1,β 来自协整回归),60/120 日 zscore;z>+2 全仓换到「相对便宜」的一只,z 回 0 平仓。A 股不能做空个股,所以社区版都退化成「两股切换」而非市场中性对冲。
- 声称绩效:胜率 88.2%(**未验证**;只做多单边,实际暴露在 beta 下)。
- 适配注意:我们的单标的引擎可扩展为「两标的切换」特例;协整 β 用滚动 OLS 即可,不必上 statsmodels 的 coint 检验(日频散户级别意义有限)。

### S14. 网格策略 v2.0(2024-2/44)+ RSRS 网格变体(2021/27)
- 核心逻辑:
  ```
  基准价 = 60 日均线;当前价 ∈ [基准×0.8, 基准×1.2] 才首仓
  每格 5%(或 2×ATR,2021/27 版),每格固定金额;涨过上一格线卖一份,跌过下一格线买一份
  分红除权日按 avg_cost 变化比例同步调整基准价
  ```
- 声称绩效:年化 13% 回撤 7%(超跌网格版,**未验证**)。
- 适配注意:日频引擎只能按收盘价判断穿格(原版分钟级),可接受;标的务必用 ETF 或大盘白马,忌小票;熊市单边下跌会持续加仓,必须加「最大层数 + 趋势过滤(RSRS<−0.7 停止买入)」。

## 三、可复用的技术点(关键公式 / 代码摘要)

### T1. KAMA / AdaptiveMA + 过滤器(2020/01)
```python
ama = talib.KAMA(close, 15)                       # 考夫曼自适应均线
filt = talib.STDDEV(ama[-15:], 15)                 # AMA 变动的标准差
if ama[-1] - ama[-2] > 0.3 * filt: 信号 = +1       # 过滤器抑制震荡期假信号
elif ama[-2] - ama[-1] > 0.3 * filt: 信号 = -1
```
配套:**吊灯止损** `close < 持仓以来最高价 − 4×ATR(15)`;**防重入**:止损后 20 根 bar 内不开仓,除非价格突破 20 日新高/新低。

### T2. RSRS 阻力支撑相对强度(2020/69,2021/27,2023/47)
```python
# 每日:用最近 N=18 天
slope, r2 = OLS(high ~ low)                        # 斜率 + 拟合度
zscore = (slope − mean(slope_series[-M:])) / std(slope_series[-M:])   # M=600~1100
rsrs_right = zscore * slope * r2                   # 右偏修正(2021/67 版)
# 信号:rsrs_right 上穿 0.7 买,下穿 −0.7 卖
```
变体:卡尔曼滤波先平滑价格再算动量(2023/47);钝化(信号需连续确认)防抖(2024-2/24)。

### T3. 动量评分 = 年化斜率 × R²(2025/26,ETF 轮动通用)
```python
y = log(close[-25:]); x = arange(25)
slope, _ = polyfit(x, y, 1)
annualized = exp(slope)**250 − 1
r2 = 1 − Σ(y−ŷ)² / ((n−1)·var(y))
score = annualized * r2                            # 涨得陡且涨得顺 → 分高
```

### T4. zscore 均值回归(2020/12)
```python
sub = close − MA(close, 20)
z = (sub[-1] − mean(sub[-60:])) / std(sub[-60:])
# z ≤ −2 买,z ≥ +1 卖(配对交易把 sub 换成两股价差,阈值 ±2,回归 0 平仓)
```

### T5. 网格参数设计(2024-2/44,2021/27)
- 基准价:60 日均线;入场区间 ±20% 内才首仓(避免高位起网)。
- 格距:固定 5%(ETF)或 `2×ATR(20)` 自适应(趋势网格版)。
- 每格金额固定(等金额非等股数),层数上限 = 总资金/每格金额。
- **除权处理**:每日比较持仓 avg_cost 与昨收 avg_cost,基准价 ×(今成本/昨成本)。

### T6. 跟踪止损变体合集
- ATR 吊灯:`stop = max_price_since_entry − 4×ATR`(S11/T1)。
- 振幅自适应:`stop = cost×(1−max近3日振幅)`、`target = cost×(1+2×振幅)`(2023/44)。
- 回撤止盈:`1 − price/max20日收盘 ≥ 0.5 且 成本已盈利>10% → 止盈`(2023/60)。
- 时间止损:`持有>30 交易日且涨幅<10% → 离场`(2023/60)。
- 涨停管理:`昨日涨停持仓,今日尾盘未封板 → 卖出;封板 → 继续持有`(几乎所有打板/小市值策略共用,是 A 股最重要的实战模块)。

### T7. 情绪 / 大盘择时指标构造
- 市场宽度:各行业成分股 `BIAS20>0` 占比(2021/45);全市场占比可作仓位信号。
- 扩散指数:指数成分股 N=20 日 `close>open` 家数占比,EMA6 下穿 EMA28 → 空仓(2025/37)。
- 拥挤率:成交额前 5% 股票的成交额占全市场比例,极值判顶底(2023/81)。
- 大盘温度计:`(mean(close[-5:]) − min(close[-220:])) / (max − min)`,<0.2 冷、>0.9 热(2025/18)。

### T8. 多因子处理流程(2021/39 等)
标准管线:因子值 → 去极值(MAD 或 3σ)→ 标准化(zscore)→ **市值中性化**(因子对 log 市值截面回归取残差)→ IC 加权 / 滚动多元回归定权重 → 综合打分排序取头部。散户日频级别可只做「去极值 + 标准化 + 等权/固定权重」。

### T9. VaR 仓位控制(2022/67)
```python
level = 1 if EMA12 > EMA50 else 0                  # 趋势档位
risk, CI = ([1.5%, 99.5%], [3.8%, 98%])[level]     # 两档风险敞口/置信度
VaR = percentile(日收益[-125:], 100 − CI)
目标仓位 = min(risk / |VaR|, 100%)                 # 波动越大仓位越轻
```

### T10. A 股适配通用过滤模板(所有实盘向策略共用)
```python
过滤:ST/*ST/退市、停牌、上市<60~300天、688/8/4 开头(科创北交)、
      当前价≥high_limit(涨停买不进)、≤low_limit(跌停卖不出)
下单:100 股整手取整;卖出前检查 closeable_amount(T+1)
```
