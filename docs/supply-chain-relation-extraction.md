# 供应链关系抽取、审核与发布

本模块把年报、半年报、招股书、机构调研、产品手册、招投标、重大合同、专利、监管审批、产能/环评及海关行业材料转换为可审计的关系候选。语言模型不是事实写入器：它只能提交主体、对象、关系、产品、金额/占比、报告期、地区、原文段落、UTF-8 span 和置信度。Rust 引擎会重新读取不可变 `source_version_id` 并逐项校验，无法在指定段落完全复现的引文会被拒绝。

## 生产链路

1. 正式披露中心或来源核验工具归档原文，保留 PDF 页码、段落、表格位置和内容哈希。
2. 后台任务逐段发现供应、客户、中标、合同、专利、审批和产能关系，同时接收模型结构化候选；预计时间只用于展示，不是截止时间。
3. 确定性校验对照证券主数据、公司别名、法人/子公司层级、产品实体、原始单位、比例范围、报告期和原文 span。
4. 所有候选进入人工审核队列。审核人可以通过、修改、拒绝、合并实体、标记保密或标记不可推断，且必须填写理由。
5. 只有人工通过并发布、置信度不低于 85%、原文可复现且非匿名/保密/不可推断的关系才投影到产业链图谱并进入 Agent 高置信查询。

任务进度和结果存放在应用状态中，切换页面不会停止。界面可展开查看已扫描证据段、候选数、校验数、待处理数、完整日志、每条候选的实际法人和上市母公司、原文页码/span、校验明细及可复制诊断。

## 困难披露

- “前五大客户”“客户一”等匿名披露保存金额和占比，但 `non_inferable=true`，不得猜测客户身份或发布图谱关系。
- 子公司签约保留实际签约主体，同时沿实体层级映射上市母公司；两者都显示在审核页，不能把母公司伪装成合同签署方。
- 联合体中标按成员拆成候选，不把牵头方的产品、份额或责任自动复制给其他成员。
- 多份独立材料对同一实体对和关系提供支持时增加交叉证据；关系类型不一致时标为冲突并强制人工解释口径与时点。

## 可回放与撤回

Schema v17 分离五类记录：`relation_extraction_runs`、`relation_candidates`、`relation_candidate_evidence`、`relation_candidate_reviews` 和 `relation_publications`。运行键包含来源版本、抽取器、模型/版本、Schema 和输入哈希；同一输入幂等复用，模型升级产生新运行，旧候选和审核不会被静默覆盖。

发布记录按候选版本追加。撤回仅撤回指定证据；同一投影仍有其他有效发布时继续保留，最后一条证据撤回后图谱边写入 `valid_to` 并从当前图查询中消失。原始候选、审核理由和撤回理由始终保留。

## Agent 与评测隔离

Agent 工具 `research_supply_chain_relations` 可以查询已经发布的关系，也可以把带精确 span 的模型候选送入审核。返回值明确分为 `agent_eligible_relations` 和 `review_only_candidate_count`；后者不能作为事实结论。

`evaluate_relations` 分别计算关系、实体和证据 span 的 precision、recall、F1。关系要求实体对、方向和类型精确匹配，证据要求同一不可变段落且 span IoU 不低于 0.5。人工审核可标记 train/dev/test；test 记录在写入和导出两处都禁止成为训练数据，避免训练/测试泄漏。内置端到端回归覆盖“新年报 → 子公司映射 → 审核 → 发布 → Agent 查询 → 撤回”。
