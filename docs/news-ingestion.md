# 财经资讯采集层

财经资讯通过稳定的 `NewsProvider` 接口接入，Agent、界面和任务事件只依赖统一资讯模型。新增来源只需要声明能力并实现一次抓取，不需要修改 Agent 工具协议或界面数据结构。

## 可信层级

从高到低分为：一手披露、授权媒体、公共聚合快讯、搜索线索。公共快讯和搜索结果用于发现事件，不自动视为已证实事实；个股研究优先合并交易所公告等一手披露。标准化记录保留来源编号、许可策略、解析器版本和不超过 32 KiB 的原始载荷，发送给模型前会移除原始载荷。

## 独立治理

每个来源分别维护启停状态、最低刷新间隔、每分钟访问上限、两次指数退避重试、连续失败熔断、最长 30 分钟冷却、增量游标和最后成功副本。最多并行采集四路；单一路异常不会阻塞其他来源。熔断或网络异常时可使用该来源的最后成功副本并标为陈旧，用户手动停用时则严格排除该来源及旧副本。

游标、启停状态和最后成功副本写入本地存储，应用重启后继续增量采集。设置页展示能力、延迟、最近成功、失败率、陈旧状态和错误类别；读取状态不会产生上游请求。

## 配置

- `ASTOCK_NEWSNOW_ENDPOINTS`：逗号分隔的 NewsNow 实例地址，每个实例独立限流和熔断。
- `ASTOCK_NEWS_PROVIDERS`：JSON 数组形式的通用资讯源配置。每项包含 `provider_id`、`display_name`、`endpoint`、`min_refresh_secs`、`rate_limit_per_minute`、`license`、`trust_tier`、`modes`，可选 `parser_version`。

端点只允许公开的 HTTP/HTTPS 地址，禁止凭证式 URL、私网/环回目标和非常用端口；刷新间隔限制为 15 秒至 24 小时，每分钟访问上限限制为 1 至 600 次，许可与解析器版本不能为空。设置页展示端点时会移除查询参数和片段，避免泄露访问凭证。

通用 JSON 来源可返回数组或 `{ "items": [...] }`，并可携带 `next_cursor`。仓库内的离线样例与故障注入测试覆盖解析契约、某一路中断、多路独立成功、瞬态重试、持久游标、重启降级和严格手动停用。
