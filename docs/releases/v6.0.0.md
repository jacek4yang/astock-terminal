# AStock Terminal v6.0.0

> Distribution policy: this public release is rebuilt on a GitHub-hosted
> Windows runner and protected by SHA-256 manifests plus GitHub OIDC/Sigstore
> artifact attestations. Authenticode: NOT PROVIDED. Windows may therefore
> display an Unknown Publisher or SmartScreen warning.

## Architecture

- Proton 0.2.1 with pinned CEF 147 is the only Windows desktop shell.
- MoonBit Agent owns task state, dynamic clarification, tool coordination,
  recovery, evidence review and report publication.
- Rust Engine owns deterministic finance, market data, storage and credentials.
- React exposes only 今日市场, Agent 智研 and 配置 as primary functions.
- The retired Dockview/IDE shell and v5 local Agent chat store are removed;
  executable recovery accepts only a task-id/sequence-matched Engine checkpoint.

## Safety boundary

The application produces research and manually reviewed investment plans. It
does not connect a broker, submit orders or perform unattended trading. Missing,
stale, conflicting or single-source material evidence is displayed and may
block publication.

`FORMALLY PROVED`, `MODEL CHECKED`, `PROPERTY TESTED`, `INTEGRATION TESTED`,
`FAULT-INJECTION TESTED`, `ASSUMED/TRUSTED BOUNDARY` or `NOT VERIFIED`.
Provider availability and correctness remain trusted external boundaries.

- GitHub quality checks for the tagged commit: REQUIRED before publication.
- GitHub OIDC/Sigstore artifact attestation: REQUIRED for every uploaded asset.
- Codex in-app browser acceptance: NOT VERIFIED on the tagged build.
- Packaged Proton/CEF 40-scenario desktop acceptance: NOT VERIFIED on the tagged build.
- MiniMax Plus and JoinQuant live flow: NOT VERIFIED; previously exposed credentials are not used or distributed.
- Authenticode: NOT PROVIDED.

The most recent predecessor local gate completed 17 checks and retained two
failures plus nine skipped interactive/external gates. Those results are not
relabelled as a full pass for the tagged build.
