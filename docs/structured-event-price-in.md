# 结构化事件、预期差与市场定价分析

本模块把一条不可变资讯修订转换成可追溯事件，并将“经营层面的影响”和“市场是否已经交易该预期”作为两个独立结论。它不从正负情绪直接生成买卖方向。

## 事件本体与证据

事件分类覆盖业绩、经营指引、订单/中标、涨价、停产、产能、政策、制裁、关税、事故、并购重组、回购、减持、解禁、诉讼、技术突破和宏观发布。事件保存主体、对象、金额、数量、原始单位/币种、对比基线、起止时间、地区、成立条件、是否正式生效、可逆性、影响期限、催化路径、验证日期和失效条件。

每个非空事实字段必须绑定不可变 `source_revision_id`、原文摘录、位置、观察时间和置信度。系统严格区分：

- 已观察事实
- 公司指引
- 市场一致预期
- Agent 分析假设
- 情景推演

来源未提供的字段保留在 `missing_fields`，不能由模型补造。事件状态按“传闻 → 待核验 → 已确认 → 已生效 → 已完成/已取消/已修订”迁移，每次迁移都单独保存理由与证据。

## 市场定价与预期差

确定性引擎读取事件前个股与沪深 300 收益、异常成交量、本地同业组合、历史估值、结构化经营影响、市场一致预期及历史同类事件样本。每项输入分别报告可用性、数值、评分贡献和解释；缺少板块、估值、一致预期或校准样本时降低量化程度，不使用其他字段替代。

输出固定拆成：

1. 基本面影响：方向、可量化经营影响及来源类型。
2. 市场机会：已交易程度、机会描述、逐项依据和“不是交易指令”的固定约束。
3. 预期差：结构化经营影响减一致预期；任一侧缺失即标记不可量化。

因此，同一事件可以同时得到“基本面正向”和“多数预期已计价/追高风险”的结果。

## 历史事件研究

历史事件在事件后 20 个交易日完整后才进入校准集，保存事件前/后异常收益、异常成交量、估值变化、方向、来源修订和数据版本。未走完观察窗口的事件不写入样本，避免未来数据泄漏。界面展示同类样本数、事后异常收益中位数与缺口，不把小样本包装成可靠规律。

## 后台任务与 Agent

资讯详情自动启动可恢复的后台任务；页面切换只停止前端轮询，不中断取数。重新打开同一事件会恢复原任务和结果。预计时间只用于展示，不是取消期限。任务详情提供当前阶段、进度、正在处理的数据、详细日志、错误复制和安全停止。

Agent 工具 `analyze_event_price_in` 只接受已归档的不可变资讯修订。它复用同一事件存储和确定性市场引擎，并要求回答逐项说明事实、指引、预期、假设、情景、缺失输入、验证日期和失效条件。
