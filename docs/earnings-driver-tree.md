# 盈利驱动树与财务冲击桥接

盈利驱动树把经营变量、财务报表和估值放进同一份不可变参数快照。它不是用一个增长率直接猜 EPS，而是明确展示每个预测行的参数、公式、报告期、单位、证据版本和不确定区间。

## 行业模型

| 行业 | 收入主公式 | 成本与风险主线 | 人工核对代表公司 |
| --- | --- | --- | --- |
| 金融 | 生息资产×净息差+手续费+投资收益 | 资金成本、信用成本、费用 | 招商银行 600036 |
| 房地产 | 结算面积×结算单价×权益比例+租赁服务 | 土地、建安、税费、结算节奏 | 保利发展 600048 |
| 资源 | 销量×商品价格×汇率+副产品 | 单位采选冶、能源、运输、资源税 | 紫金矿业 601899 |
| 制造 | 分产品销量×ASP，受产能和利用率约束 | 材料单耗、采购价、能源、人工、折旧 | 中际旭创 300308 |
| 消费 | 分品类销量×ASP×渠道确认比例 | 原料、包装、生产、渠道库存与提价时滞 | 贵州茅台 600519 |
| 软件 | 订阅席位×ARPU+续费+实施/授权 | 交付人工、云资源、渠道分成、摊销 | 用友网络 600588 |

“人工核对”只表示行业公式模板经过会计逻辑核对，不表示任何公司预测值已经人工背书。

## 参数来源纪律

参数来源严格分为六类：历史事实、管理层指引、市场一致预期、用户假设、AI 助手假设、行业先验。历史事实必须带不可变证据版本、报表字段位置、报告期、公告日和单位。指引与一致预期必须保留供应商和版本；当前数据源未提供时保持缺失。行业先验只用于宽区间，不能显示为公司事实。

`parameter_snapshot_id` 对收入、成本、现金流、资产负债表、总股本和行情快照做稳定哈希。盈利驱动树和 DCF 都返回该编号；两者编号不同即表示口径不同，不能拼接为同一结论。完整驱动树以 `snapshot_id` 写入 `earnings_driver_snapshots`，历史报告可以确定性回放。

## 缺失数据处理

F10 合并报表通常没有分产品销量、ASP、产能利用率、原料单耗、渠道库存等结构性变量。系统会在 `missing_core_drivers` 逐项列出，并将 `exact_eps_available` 设为 `false`。只要营业收入、成本/毛利或总股本缺失，系统停止计算情景 EPS 并给出拒绝原因，不会把缺失值补成零。

有合并报表但缺分部数据时，系统可以展示 Bear/Base/Bull 和 Monte Carlo 宽区间，界面必须同时展示“不是精确 EPS”的提示。

## 计算和反向求解

- 收入、毛利润、营业利润、归母净利润、EPS、经营现金流、资本开支和自由现金流逐行保存公式及依赖参数。
- Bull/Base/Bear 使用同一参数快照的低/中/高区间。
- 双变量敏感性同时改变收入增长与毛利率。
- Monte Carlo 使用由快照编号派生的确定性种子；相同快照必得相同结果。它是参数区间传播，不是收益概率。
- 现价隐含假设在固定 WACC 9%、永续增长 2.5% 和五年显式期下反向求解 FCF 增长率。现价超出可解值域时明确拒绝外推。

## 供应链冲击

`run_earnings_driver_shock` 接受销量、产品价格、产能、原料、能源、运输、汇率、期间费用和营运资金冲击。冲击可以绑定 `evidence_version_id`，并保存为新的冲击快照。输出不是情绪分数，而是相对基准情景的收入、毛利、营业利润、归母净利润、EPS、经营现金流和自由现金流桥接表。未知冲击类型会明确报出，不会静默套用错误映射。

## 命令与 Agent

- `get_earnings_driver_tree(symbol)`：构建、保存并返回完整驱动树。
- `run_earnings_driver_shock(symbol, shocks)`：生成并保存财务冲击桥接。
- `get_earnings_driver_snapshot(snapshot_id)`：不重新抓取数据，直接回放不可变快照。
- Agent 工具 `analyze_earnings_drivers`：提供压缩摘要，完整参数、证据和敏感性结果进入缓存供下钻。

股票详情页的“盈利驱动树”支持公式逐层展开、情景图、Monte Carlo、隐含假设、冲击试算、来源筛选、分页和证据版本复制。
