# 可复现量化研究工作台

量化实验室把 `astock-quant` 的统计函数统一包装成一条可由界面和智能助手共同调用的研究流水线。它用于关系发现与稳健性验证，不直接生成交易指令。

## 完整研究契约

一次研究必须保存：股票池、价格/普通收益率/对数收益率口径、日/周/月频率、起止日期、前/后/不复权、缺失值处理、滚动窗口、最大滞后、控制变量、Bootstrap 与置换次数、显著性阈值、多重检验方法、配对和样本预算、固定随机种子、数据版本及函数版本。

界面和 Agent 都调用 `quant_research_json`，因此相同版本化输入与配置会得到相同数值和 `snapshot_id`。历史快照直接重放保存结果；重新取数属于新的数据版本，不会覆盖旧快照。

## 推断与防止挑结果

- Pearson、Spearman、Kendall、距离相关、互信息和 lead-lag 使用确定性移动块 Bootstrap 区间与置换显著性。
- Granger 使用线性模型 F 检验，同时给出 Bootstrap 统计量区间；措辞固定为“预测性 Granger 关系”，不写成结构因果。
- 全部配对统一做 Benjamini-Hochberg FDR 校正（可显式选择更保守的 Bonferroni）；界面同时展示原始和校正后的 p 值。
- 每条结果显示实际参与检验的有效样本 N。互信息明确说明没有通用标准参数 p 值。

## 稳健性与性能预算

每个关系同时切分年度、共同上涨/下跌、高/低波动、滚动窗口、不同样本量、训练/留出样本，并执行 1% 缩尾异常值敏感性；lead-lag 另做滞后参数敏感性。结论必须一起报告效应、区间、FDR 后显著性和跨窗口稳定性。

股票对数按 O(n²) 增长。工作台在执行前显示请求/实际配对数、单对最大样本、复杂度与预计运算量；超出 `max_pairs` 时按固定种子做确定性配对抽样，高成本指标按固定间隔压缩单对样本。后台任务没有硬超时，提供行情获取数、当前关系、有效样本、进度、剩余时间、日志、复制诊断和安全取消。

## 因果语言边界

- 相关：只描述共同变化。
- 预测领先：只描述样本中的时间先后。
- Granger 预测因果：只表示加入一方历史值后改善另一方的线性预测。
- 结构因果：需要额外的识别假设、自然实验或随机实验，以上统计量均不能单独证明。
