# 数据源与治理

## 已接入

| 数据源 | 主要能力 | 治理 |
|---|---|---|
| TDX TCP | 证券列表、实时快照、五档、K 线、当日/历史分时 | 懒探测、连接池、心跳、黑名单、失败切换 |
| 腾讯/新浪 | K 线主备通道 | 主机池、熔断、质量过滤 |
| 东方财富 | 全市场列表、行情补充、资金流、分钟、F10、估值、数据中心 | TTL、字段级降级、模式兼容解析 |
| Tushare | 可选 K 线、日指标、财务/公司行为补充 | Token 可选、共享限频 |
| 问财 OpenAPI | 可选消息面与研究数据 | 最多两路并发、瞬态错误单次重试、缓存 |
| 聚宽 | 可选研究数据 | 串行间隔与凭证隔离 |

“利用所有上游”指按字段能力补齐和交叉核验，不代表对同一已命中缓存的字段同时请求所有 provider。

## 频率与重试

- 行情 HTTP：同主机健康间隔 75ms；8 秒超时；失败惩罚从 100ms 翻倍到 30s；主机切换间隔 300ms。
- 缓存：实时 2s、K 线/搜索 15s、全市场 60s、市场宽度 120s。
- provider 熔断：WAF 立即打开；网络/超时/429 连续三次打开；10 分钟后半开试探，失败冷却翻倍，最高 1 小时。
- MiniMax：额度快照 30s；建流瞬态错误最多五次，1s 指数全抖动，单次等待上限 60s，遵循 `Retry-After`。

## 缺失与冲突

没有提供的字段保持 `None`，UI 显示“—”和缺失原因，不能变成 0。多源冲突先经过格式、范围、时点和孤立尖峰校验，再按字段能力与质量选值；来源和时间保留到 UI。

可选凭证存储状态可在设置页查看，密文本身不回显。
